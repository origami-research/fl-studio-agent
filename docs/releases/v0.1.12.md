# fl-studio-agent 0.1.12

The agent now opens production guides when it needs them, and `run`'s description is short enough that no client cuts it.
`fl.guide()` lists 14 guides (arrangement, mixing, seven genre playbooks, and the listening, revise, sidechain, sounds and chops recipes); `fl.guide("house")` prints one.
This release also fixes the tool errors the agent hit most often in our showcase runs.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then set up FL Studio once, with FL closed (on Windows, in a terminal opened as administrator on your own account):

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

Then open `FLMCP Agent.flp` in FL Studio before you ask for music; it carries the Bridge.

## Updating from 0.1.11

Nothing to rerun.
`fl-mcp-install` keeps an existing `FLMCP Agent.flp`, so its channel notes still give the old ranges: Bass is silent below MIDI 36 (C2), not 28, and Sax above 72, not 75.
A new agent project (rename the old one, then rerun `fl-mcp-install`) has the corrected text.

## New

- **Guides** (#339, #341).
  `fl.guide()` prints the guide index and `fl.guide(name)` prints one guide, each with one worked example the agent can run.
  New craft guides: `arrangement` (bar maps, one pattern per section, building energy, keeping repeats alive), `mixing` (balance, headroom, EQ regions, the template's sends, panning) and seven genre playbooks: `house`, `phonk`, `trap`, `lofi`, `cinematic`, `dnb` and `pop`.
  The recipes that lived in `run`'s description moved into guides: `listening`, `revise`, `sidechain`, `sounds` and `chops`.
  Genre facts are curated conventions, not measured on reference tracks.
- **A generated `run` description** (#339).
  It is `run`'s own contract plus a one-line index per SDK area and the guide index, 3,878 characters, down from 6,568, so Claude Code no longer cuts it at 4,096.
  Details come from `help(fl.x)` inside `run`, and `docs/sdk-reference.md` is generated from the same docstrings.
  The server also sends one line of instructions naming `run`, for clients that defer tools.
- **`--workspace-only`** (#339): a server with no FL session, for computer-use hosts.
  Every `fl` call but `fl.guide()` is refused there, and `run`'s description is the kernel contract and the guide index only.
- **`Render.silent`** (#342): a render or stem with nothing above BS.1770's -70 LUFS gate says so, in its repr and its action line, before the agent measures it.

## Changes

- **One `Effect` type** (#342).
  `fl.effect`, `fl.mixer` and `load_preset(...).effect` now all hand out an `Effect` with `params()` and `set_param()`; before, two of them returned a plain record without them.
  `fl.effect(track, slot)` raises on an empty slot.
- **Sampler channels** (#342): `params()`, `set_param`, presets and automation on a sampler channel now say it is a sampler and name what it does have (`set_levels`, an effect on its mixer track), instead of FL's "Plugin not valid".
- **The agent project's ranges** (#342): Bass plays MIDI 36-60 and Sax stops at 72, as measured live; MIDI 60 is named C4, as in the SDK.
  The lofi, pop and house guides no longer play Bass below 36.
- **Docs the agent reads** (#342): `SceneSummary.summary` is the digest as text; a `Render` is the WAV's path; renders land in the run's renders folder, so read the returned `Render`; `Sound.score` is None for a name-only match; `fl.meters` gives `peak_dbfs` None for silence.

## Fixes

- **A sample named "... #6.wav" did not confirm** (#342): FL drops a trailing " #n" from a channel name, so names are now compared without it.

## Known issues

- The sound model and index are still unpublished, so `fl.sounds` ranks by name only and `like=` is refused.
- On Intel macOS, and on Python 3.15 and later, onnxruntime has no wheel, so `fl.sounds` matches by name only there even once the model is published.
- FL keeps automation about 0.1 s later than asked for (measured on one machine); the pumping recipe starts each dip that much early.
- On Windows, a program that opens the null device `NUL` itself is still refused inside `run`; use `subprocess.DEVNULL` or `os.devnull`.
- A render plays in real time, so `stems=` takes one play per stem.
