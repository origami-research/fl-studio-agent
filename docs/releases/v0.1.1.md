# fl-studio-agent 0.1.1

One-step install for every MCP client.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then, with FL Studio closed, set it up once:

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

## Changes

- `fl-mcp-install` is the one FL-side setup command on macOS and Windows: it creates the agent project, installs the scripts and the MIDI assignment, checks the loopMIDI ports on Windows, and installs a built Bridge with `--bridge PATH`. Every step says `installed` or `already current`, so rerunning it is safe and is how you update.
- New `fl-studio-agent` command (same server as `fl-mcp`), so `uvx fl-studio-agent` works; `fl-mcp --version` and `--help` answer without starting the server.
- Claude Desktop bundle (`fl-studio-agent.mcpb`) attached to this release.
- Listed in the MCP Registry as `io.github.origami-research/fl-studio-agent`.
- The install commands pin Python 3.12, because the MIDI dependency (python-rtmidi 1.5.8) has no wheels for newer Pythons.

The native Bridge plugin is still built from source ([SETUP.md](https://github.com/origami-research/fl-studio-agent/blob/main/SETUP.md#the-bridge-plugin)).
