# fl-studio-agent 0.1.2

The Bridge plugin ships prebuilt: setup is one command, with nothing to build.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then set up FL Studio once, with FL closed (on Windows, in a terminal opened as administrator):

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

## Changes

- `fl-mcp-install` now installs the native Bridge plugin (live writes and `render`) for you. It downloads this release's library for your OS, checks it against `SHA256SUMS`, and installs it into FL's plugin folder. `--bridge PATH` installs your own build, and `--no-bridge` skips it.
- This release carries the Bridge for macOS (universal: Apple Silicon and Intel) and Windows x64, built by the release workflow, with `SHA256SUMS` and `BRIDGE-NOTICE.txt`.
- `fl-mcp-doctor` reports the installed Bridge: its path, source, SHA-256, and the FL build it was installed for.

## Notes

- The Bridge libraries are not code-signed; [SETUP.md](https://github.com/origami-research/fl-studio-agent/blob/main/SETUP.md#the-bridge-plugin) says what macOS and Windows show.
- The Bridge is built with Image-Line's FL Studio plugin SDK headers. FL Studio is a trademark of Image-Line, and this project is not affiliated with Image-Line (see `BRIDGE-NOTICE.txt`).
