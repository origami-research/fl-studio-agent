# Contributing (draft)

This is a launch draft for a future public repository. The repository is not
open for external contributions or redistribution yet.

After launch, contributors should:

1. Read `AGENTS.md`, `taste.md`, and the relevant design document before editing.
2. Keep a change narrow and remove superseded behavior in the same pull request.
3. Add or update tests and documentation when behavior or an invariant changes.
4. Run the smallest relevant verification and report both its command and result.
5. Never add FL Studio SDK files, credentials, local projects, generated artifacts,
   or private product material.

Maintainers will publish supported platforms, a code of conduct, security
reporting instructions, and a compatibility policy before accepting outside
contributions.
