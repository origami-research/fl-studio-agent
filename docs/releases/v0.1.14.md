# fl-studio-agent 0.1.14

Reading the whole project now takes one short printout.
`print(fl.scene())` shows the patterns, channels, playlist and mixer together, and `fl.channels` and `fl.mixer` print one line per object.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then set up FL Studio once, with FL closed (on Windows, in a terminal opened as administrator on your own account):

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

Then open `FLMCP Agent.flp` in FL Studio before you ask for music; it carries the Bridge.

## Changes

- **`fl.scene()` is the whole project in one compact read** (#346).
  It also reads the patterns, the playlist and the mixer, and its printout is a digest: the project notes once, tempo and key, the playlist's extent, then one line per pattern, per channel and per mixer track in use, then the automation.
  Levels print to two places and runs of numbers print as ranges.
  When FL does not answer in time, `fl.scene()` leaves out the patterns and the mixer, says so in one line, and reads the rest from the saved song instead of raising.
- **`fl.channels` and `fl.mixer` print one line per object** (#347).
  A channel prints as `Channel(0 'Kick' -> 4, vol 0.78)`; a mixer track prints its volume, effects by slot and the sends that are on.
  `fl.mixer` lists the tracks in use, and `fl.mixer.empty` counts the rest.
  The objects keep every field and FL's exact values; only the printouts change.
- **`PlaylistClip.arrangement`** (#346) names the arrangement a clip belongs to, so a song with several arrangements is not merged into one.

Printing the scene, `fl.channels`, `fl.patterns` and `fl.mixer` together on the agent project was about 23,600 characters before this release; the estimate after it is about 11,800.

## Removed

- **`SceneSummary.summary`** (#346).
  Print the `SceneSummary` instead; the parts stay as fields (`patterns`, `channels`, `mixer`, `playlist`).

## Known issues

- The agent project's channel notes still carry genre hints ("the drift phonk lead", "for house and electronic music").
- The sound model and index are still unpublished, so `fl.sounds` ranks by name only and `like=` is refused.
- On Intel macOS, and on Python 3.15 and later, onnxruntime has no wheel, so `fl.sounds` matches by name only there even once the model is published.
- FL keeps automation about 0.1 s later than asked for (measured on one machine); the `sidechain` guide starts each dip that much early.
- On Windows, a program that opens the null device `NUL` itself is still refused inside `run`; use `subprocess.DEVNULL` or `os.devnull`.
- A render plays in real time, so `stems=` takes one play per stem.
