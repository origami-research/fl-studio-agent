# Claude Desktop bundle

Source of the `fl-studio-agent.mcpb` asset on each GitHub release.
`manifest.json` and `pyproject.toml` are generated by `scripts/install_links.py`; `scripts/build-mcpb.sh` validates and packs them.
The bundle uses the MCPB `uv` runtime: Claude Desktop's uv installs the pinned `fl-studio-agent` release from PyPI, so the bundle runs the same package as every other client.
