# fl-studio-agent 0.1.11

The agent can now choose a sound by how it sounds, and listen before it commits.
`fl.sounds("punchy house kick")` ranks FL's stock samples and instrument presets, and two free CC0 sample packs, by sound; `fl.audition` plays a preset so the agent can hear it.
A `run` call now has one time budget, so a slow cell ends with an answer instead of none.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then set up FL Studio once, with FL closed (on Windows, in a terminal opened as administrator on your own account):

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

Then open `FLMCP Agent.flp` in FL Studio before you ask for music; it carries the Bridge.

## Updating from 0.1.10 or earlier: rerun fl-mcp-install

Close FL and run `fl-mcp-install` again (the command above), then reopen FL.
It downloads the CC0 sample packs and installs the new agent project, whose drum channels point at `fl.sounds`.

## New

- **Choose a sound by how it sounds** (#331).
  `fl.sounds(query)` searches every FL stock sample, every stock instrument preset and the CC0 packs, best match first.
  `query` describes the sound ("warm analog pad slow attack"); `like=` matches a reference instead: a sound from the list, or an audio file the agent wrote.
  Each result has a `score` and measurements: length, pitch, decay, brightness, and low and high energy.
  Ranking by sound uses LAION's CLAP music model (CC0) on the CPU, with an index of FL's stock sounds that holds numbers and paths, none of FL's audio.
  The model and index are not published for download yet, so this release matches sounds by the words in their names; `fl-mcp-install` says so on its `sound_search` line, and `fl-mcp-doctor` reports `sound_search: by name only` with the reason.
  Results matched by name have `score` None.
- **`fl.audition(preset)`** loads an instrument preset on the agent project's Audition channel, plays a short phrase (or the notes you pass) on it alone and records it, so the agent can listen with `fl.read_wav` before loading the preset for real.
  `fl.read_wav` now also reads FL's WavPack and FLAC stock samples.
- **CC0 sample packs**: `fl-mcp-install` downloads 181 one-shots from VCSL and VSCO 2 Community Edition (percussion, a real drum kit, melodic one-shots), each pinned by SHA-256; see NOTICE.md.
- **Guidance for the agent** (#334): make one musical change per call and check it with a render or `fl.meters` before the next; after a render, compare loudness, true peak, spectral balance and energy per section with a reference (or about -14 LUFS with true peak below -1 dBTP), fix the biggest gap, and render again.

## Changes

- **One time budget per `run` call** (#335, fixes #333).
  A call has 600 s from the moment it is made, covering the wait for the kernel, the cell's own work and every `fl` call.
  Before, only the cell's own computation counted, so a cell of slow renders could run past a client's timeout and get no answer.
  Past the budget, the cell is interrupted between `fl` calls, keeps its variables, and the result lists what FL did; a render or automation that would not fit is refused before FL changes anything, with the time it needs and the time left.
  `FLMCP_RUN_BUDGET_SECONDS` sets another budget.
- **`fl.kit` and the curated drum kits are removed.** Choose drums with `fl.sounds` and listen to them.

## Fixes

- **SimSynth presets did not load** (#331): FL names the plugin "SimSynth Live", which the loader did not accept.
- **One refused preset broke every later audition** (#331): a preset FL refused left the Audition channel renamed, so the next `fl.audition` could not find it.

## Known issues

- Until the sound model and index are published, `fl.sounds` ranks by name only and `like=` is refused.
- On Intel macOS, and on Python 3.15 and later, onnxruntime has no wheel, so `fl.sounds` matches by name only there even once the model is published.
- FL keeps automation about 0.1 s later than asked for (measured on one machine); the pumping recipe starts each dip that much early.
- On Windows, a program that opens the null device `NUL` itself is still refused inside `run`; use `subprocess.DEVNULL` or `os.devnull`.
- A render plays in real time, so `stems=` takes one play per stem.
