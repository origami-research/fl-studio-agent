# fl-studio-agent 0.1.13

The text the agent reads now leaves musical choices to you and to the agent.
`run`'s description and the guides keep how this environment works and the facts behind it, and drop the rules that pushed every song toward one template.
The guides are optional reference, and there are six of them.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then set up FL Studio once, with FL closed (on Windows, in a terminal opened as administrator on your own account):

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

Then open `FLMCP Agent.flp` in FL Studio before you ask for music; it carries the Bridge.

## Updating from 0.1.12

Nothing to rerun.

## Changes

- **`run`'s description** (#344).
  The "How to work" block (one musical change per call, keep `notes.md`) becomes two facts: `fl.scene()` is the project in one digest, and hearing takes time (meters take seconds, a render plays in real time).
  It is 3,080 characters with an FL session, down from 3,878, and 1,787 with `--workspace-only`, down from 2,324.
- **Guides are optional reference** (#344).
  The guide index, every guide's description and `fl.guide()`'s docstring say so.
  `listening`, `sounds`, `sidechain`, `chops`, `arrangement` and `mixing` keep how things work here (FL's automation lag, clips cannot be moved once placed, what the mixer holds, a sampler plays at its own pitch on MIDI 60) and drop mix order, energy-build rules, phrase lengths, EQ rules of thumb and genre advice.
  All six guides together are 12,159 characters, down from 50,677.

## Removed

- **The seven genre playbooks and `revise`** (#344).
  `house`, `phonk`, `trap`, `lofi`, `cinematic`, `dnb` and `pop` are gone: the step patterns and bar maps steered every song toward one shape.
  `revise` prescribed a loop and a -14 LUFS target; comparing against a reference you give is one line in `listening`.
  `fl.guide("house")` now raises an error that lists the six guides.

## Known issues

- The agent project's channel notes still carry genre hints ("the drift phonk lead", "for house and electronic music").
- The sound model and index are still unpublished, so `fl.sounds` ranks by name only and `like=` is refused.
- On Intel macOS, and on Python 3.15 and later, onnxruntime has no wheel, so `fl.sounds` matches by name only there even once the model is published.
- FL keeps automation about 0.1 s later than asked for (measured on one machine); the `sidechain` guide starts each dip that much early.
- On Windows, a program that opens the null device `NUL` itself is still refused inside `run`; use `subprocess.DEVNULL` or `os.devnull`.
- A render plays in real time, so `stems=` takes one play per stem.
