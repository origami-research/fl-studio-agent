# fl-studio-agent 0.1.18

`fl.load_sample` now loads recordings from a phone or a browser (M4A, WebM, Opus), so a file you give the agent can go straight into a sampler.

## Install

```bash
claude mcp add --scope user fl-studio -- uvx --python 3.12 fl-studio-agent
```

Cursor and VS Code: use the install buttons in the [README](https://github.com/origami-research/fl-studio-agent#quick-start).
Claude Desktop: download `fl-studio-agent.mcpb` below and open it.
Then set up FL Studio once, with FL closed (on Windows, in a terminal opened as administrator on your own account):

```bash
uvx --python 3.12 --from fl-studio-agent fl-mcp-install
```

Then open `FLMCP Agent.flp` in FL Studio before you ask for music; it carries the Bridge.

## Updating from 0.1.17

Nothing to rerun.

## Changes

- **`fl.load_sample` loads every audio file `fl.read_wav` reads** (#358).
  It used to refuse M4A and WebM, so the agent could measure a phone or browser recording but not sample it.
  It now takes WAV, FLAC, AIFF, MP3, Ogg, Opus, M4A and WebM.
- **The docs say your files can be used** (#358).
  `help(fl.load_sample)`, `help(fl.read_wav)` and `help(fl.sounds)` say a file you put in the workspace can be loaded, measured or matched, and the listening guide no longer treats it as a reference only.

## Known issues

- `fl.scene()` takes about 4 s, more with many patterns.
- The project's notes follow a channel's name, so a channel FL renames (a loaded sample or preset) loses its line.
- The sound model and index are still unpublished, so `fl.sounds` ranks by name only and `like=` is refused.
- On Intel macOS, and on Python 3.15 and later, onnxruntime has no wheel, so `fl.sounds` matches by name only there even once the model is published.
- FL keeps automation about 0.1 s later than asked for (measured on one machine); the `sidechain` guide starts each dip that much early.
- On Windows, a program that opens the null device `NUL` itself is still refused inside `run`; use `subprocess.DEVNULL` or `os.devnull`.
- A render plays in real time, so `stems=` takes one play per stem.
- The MCP server's description (`...; confined=true`) is meant for the host, but some MCP clients may show it.
